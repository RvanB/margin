# Margins

A web utility for setting margins for book printing.

- Upload PDFs or images of your content
- Flip through page turner with thumbnail previews
- Customize page size and text block dimensions
- Adjust content region for each page
- Apply van de Graaf overlay for a pleasing baseline
- Display measurements for translation to real media
- Save and load page dimensions and per-page settings to continue where you left off
- Export at the source image resolution, with margins added

https://rvanbronkhorst.com/margin/
